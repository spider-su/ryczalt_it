Polityka prywatności — Ryczałt IT

Ostatnia aktualizacja: 22 listopada 2026 r.

Ryczałt IT jest niezależną aplikacją mobilną i nie jest oficjalną aplikacją Ministerstwa Finansów.

Przetwarzane dane

Użytkownik może wprowadzić NIP i token KSeF. Aplikacja pobiera publiczne dane firmy, w tym nazwę, REGON, adres i status VAT. Profil i token są zapisywane lokalnie z użyciem zabezpieczonego magazynu systemowego.

Usługi Ministerstwa Finansów

Na żądanie użytkownika aplikacja wysyła NIP do oficjalnego rejestru podatników VAT i nawiązuje bezpośrednie połączenie z oficjalnym API KSeF w celu sprawdzenia uwierzytelnienia. Instytucje prowadzące te usługi przetwarzają informacje o połączeniach według własnych zasad.

Konta i serwery

Bezpłatny tryb nie wymaga konta Ryczałt IT ani wysyłania danych do własnego serwera producenta. Nie sprzedajemy tokenów KSeF reklamodawcom.

Usuwanie danych

Użytkownik może usunąć lokalny profil i token w aplikacji. Usunięcie tokenu z telefonu nie unieważnia go w KSeF.

Funkcje

Obecna wersja nie pobiera faktur ani nie oblicza PIT, VAT lub ZUS.
